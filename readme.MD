# Agentic Coding Study

Develop a simple app to create learning games from resources. Compare the lastest agent models with Claude, Codex, Copilot, and Antigravity. Lovable included for fun.

## Prompt

Build a web app with users. Users can upload learning resources and then create a game to study the resources with. There are two games. One game has related knowledge pairs extracted from the resources arranged in blocks on the screen, the user matches between them by clicking on one of knowledge pairs which becomes highlighted and then clicking on the matching knowledge pair which results in either a success or failure highlight; if it is a success the blocks are no longer interactable but if it is failure they can be interacted with again clearing the previous highlights. The other game creates two high level concepts from the resources and generates knowledge items for each high level concept, the user is then presented with two columns, one for each high level concept, and blocks of knowledge items which are dragged into the correct column by the user; if the column is incorrect the block returns to where it was, if it is correct it is placed in the column.
